# Security Policy

## Supported Versions

Currently, the main branch and recent deployments receive security updates.

| Version | Supported          |
| ------- | ------------------ |
| Main    | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Security is a priority at Mondal Labs. If you discover a security vulnerability within this project, please send an email to **[mondallabs.official@gmail.com](mailto:mondallabs.official@gmail.com)** instead of creating a public issue.

Please include the following information in your report:
- A description of the vulnerability and its impact.
- Steps to reproduce the issue.
- Potential mitigation or fix (if known).

All security vulnerabilities will be promptly addressed.
